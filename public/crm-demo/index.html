    About this demo

    This is a shared, open demo. Use sample details, since anyone with the demo link can read its records. The two seed contacts use fictional sample portraits. New contacts use initials. Records live in this page’s HTML. Counts are computed by Pagelove on each read; the browser builds the contact and conversation views from those records. Saving a conversation also updates the next check-in date. A static local preview can show the interface, but needs Pagelove to save changes.
